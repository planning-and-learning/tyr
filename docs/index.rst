tyr
===

tyr is a planning and Datalog library with grounded and lifted reasoning, in C++ with Python bindings (``pytyr``).
The `README <https://github.com/planning-and-learning/tyr#readme>`__ introduces it; these pages document parts of
it in detail.

The rules the planning-and-learning libraries share are documented in
`brokkr <https://planning-and-learning.github.io/brokkr/>`__.
